# easyNote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build easyNote, a static-site handwriting whiteboard with shape snapping, Smart Script, a handwritten calculator, inline graphs and offline CNN recognition that reads the user's real handwriting.

**Architecture:** The app is plain ES modules with no build step, split into `core / canvas / shapes / script / recog / math / graph / notes / ai`. Pure logic has no DOM access and is unit-tested with `node:test`. The DOM layers are tested end to end with Playwright. The CNN is trained offline: training data is rendered by the app's own `recog/raster.js`, training runs in PyTorch on CPU, and the weights ship as int8 in `models/`.

**Tech Stack:** Vanilla JS (ES2022 modules), Canvas 2D, Pointer Events, `node:test`, Playwright (Chromium), Python 3.13 + PyTorch CPU + NumPy (training only), esbuild (one-off SDK vendoring only), GitHub Actions Pages.

**Spec:** `docs/superpowers/specs/2026-10-25-easynote-design.md`

## Global Constraints

- No build step for the site. Everything the browser loads is committed as-is. No runtime CDN.
- Node ≥ 18 for scripts and tests. Training uses Python 3.13 in `.venv-train/`, which is gitignored.
- Pure modules (`core`, `shapes`, `script`, `recog`, `math`, `graph/plot.js`, `notes/export.js` PDF writer) must not touch `window` or `document`.
- Points are world coordinates `[x, y, pressure, t]`. Pressure is in 0..1.
- Thresholds:
  - hold-to-snap: 4 px for 450 ms
  - release-snap: diagonal > 35% of the shorter viewport side
  - shape blend: 0.15 of the original wobble
  - Smart Script: 1.2 s after the last stroke
  - math re-read: 700 ms idle
  - learned-digit confidence: ≥ 0.95, with 5 samples per digit
  - answers: ≤ 7 significant digits
  - Claude timeout: 8 s
- Graph cards:
  - `pointer-events: none` on the body; only the expand and close buttons take pointer input
  - fade to 15% opacity while drawing
  - phone: card width 120–220 px, or placed below the equation
  - framing: x about ±5
- Trig defaults to degrees. `log` is base 10.
- Claude:
  - default model `claude-opus-5-5`
  - SDK at `vendor/anthropic-sdk.mjs` (bundled locally)
  - falls back offline on any failure
- User fixtures are test data only and never used for training.
- Do not push. The final push happens only after the user approves (Task 20).
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Writing over or near an answer.** Answer strokes are generated, so they must never be read back as input. Erasing part of a line must remove or refresh its answer. Owned by Task 13: tests `answer strokes excluded from reading` and `erasing a line's strokes removes its answer`.
2. **Discontinuous functions** such as `y = 1/x` and `y = tan(x)`. The plot must break the path at jumps instead of drawing vertical lines, and framing must ignore the asymptotes. Owned by Task 15: tests `plot breaks at discontinuity` and `frame ignores asymptote`.
3. **`pointercancel` mid-stroke** (iOS gesture steal) and a pen hovering without contact. The stroke is committed up to that point or discarded, and nothing is left dangling. Owned by Task 4: e2e `pointercancel ends stroke cleanly`.
4. **localStorage full** on large notes. The app warns with a toast and keeps working. Owned by Task 16: test `quota error shows toast and keeps doc`.
5. **Far-from-origin canvas** (panned 1e6 px) with zoom at its limits. Ink still renders and hit-tests correctly. Owned by Task 3: test `screenToWorld round-trips at 1e6 offset and scale 8`.

**Interfaces:**
- Produces:
  - `rasterize(strokes) → Float32Array(784)`, values in 0..1. Steps:
    1. Fit the longer side to 20 px. The shorter side keeps its aspect ratio, with a minimum of 2 px.
    2. Line width is `max(1.6, 20 / 9)` px.

  - Model format: `json = {layers: [{type, shape, scale, offset}], classes}`, `bin` = Int8Array

  - `x` as "ɔc" (1 or 2 strokes, ± loop)

  - curly `2`

  - left or right 30–60% slices of any class
